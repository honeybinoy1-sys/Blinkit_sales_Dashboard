# Blinkit Sales Dashboard

## Project Overview
This project is a Power BI dashboard created to analyze and visualize the Blinkit Sales dataset.

## Dashboard Visualizations
- Sales by Outlet Type (Clustered Bar Chart)
- Sales by Item Type (Horizontal Bar Chart)
- Sales by Outlet Size (Donut Chart)
- Sales by Outlet Location Type (Column Chart)
- Outlet Establishment Year vs Sales (Line Chart)
- Item Visibility vs Sales (Scatter Plot)
- Average Rating by Item Type (Column Chart)
- Fat Content vs Sales (Donut Chart)
- Outlet Size vs Average Rating (Stacked Column Chart)

## Tool Used
- Microsoft Power BI

## Dataset
- Blinkit Sales Dataset
- https://www.kaggle.com/datasets/architgoel29/blinkit-dashboard
