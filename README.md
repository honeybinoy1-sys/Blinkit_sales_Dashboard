# Blinkit Sales Dashboard

## Project Overview
This project is a Power BI dashboard built using the Blinkit Dashboard dataset from Kaggle. The dashboard looks at sales performance across products and outlets and also includes product visibility, ratings and advanced sales analysis.

## Dataset
Source: Kaggle – Blinkit Dashboard
https://www.kaggle.com/datasets/architgoel29/blinkit-dashboard
The dataset contains product and outlet-related fields such as:
Item Type
Item Fat Content
Item Visibility
Item MRP
Sales
Rating
Outlet Size
Outlet Location Type
Outlet Type
Outlet Establishment Year

## Dashboard Visualizations
Sales by Outlet Type – Clustered Bar Chart
Sales by Item Type – Horizontal Bar Chart
Sales by Outlet Size – Donut Chart
Sales by Outlet Location Type – Column Chart
Outlet Establishment Year vs Sales – Line Chart
Item Visibility vs Sales – Scatter Plot
Average Rating by Item Type – Column Chart
Total Sales by Item Fat Content and Outlet Location Type – Donut Chart
Average Rating by Item Type and Outlet Location Type
Total Sales by Item Type – Waterfall Chart
Sales and Rating – Matrix
Total Sales – Decomposition Tree
